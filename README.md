# Aone

**강의 자료를 넣어두면 학기 내내 스스로 정리하고, 시험이 다가오면 먼저 챙겨주는 대학생 학습 에이전트**

2026 AI·SW중심대학 디지털 경진대회 SW부문 본선 출품작 · 충남대학교 **멋쟁이 차차처럼**

**웹 데모 → https://aone-five.vercel.app** (설치·로그인·API 키 없이 바로 열람)

---

## 이런 문제를 풉니다

학기가 시작되면 자료가 쌓입니다. 강의 슬라이드, 녹음, 필기, 실습 파일, 선배가 준 족보. 과목마다 규칙도 제각각입니다.

정작 시간이 가장 많이 드는 일은 파일 정리가 아니라 **그 다음**입니다. 흩어진 자료를 잇고, 무엇이 중요한지 가려내고, 시험 범위에 맞추는 일. 시험 기간에 이 일을 하다 보면 정작 이해할 시간이 없습니다.

범용 AI에 슬라이드를 던지면 요약은 나옵니다. 하지만 **이 교수님이 뭘 다섯 번 강조했는지, 기출과 뭐가 겹치는지**는 나오지 않습니다. 학기 내내 곁에서 맥락을 쌓아온 도구가 아니기 때문입니다.

---

## 어떻게 동작하나

**학생이 하는 일은 하나 — 자료를 폴더에 넣는 것.** 버튼을 누를 필요가 없습니다.

```
자료를 넣는다  →  에이전트가 알아서 돈다  →  시험이 다가오면 먼저 챙긴다
 PDF·PPT           지각 → 기억 → 추론 → 행동      우선 복습 · 학습 가이드
 전사본·필기·족보    개념 추출·근거 부착·신호 감지     예상문제 · 모의고사
```

폴더에 파일이 들어오는 순간 감지해서 분석을 시작하고, 개념 단위로 분해해 로컬 지식베이스에 쌓습니다. 자료가 쌓일수록 판단이 정교해집니다 — 실제 한 학기 데이터에서 개념이 13개에서 92개로 자랐습니다.

## 기능

### 홈 — 이번 주가 한눈에

- **주간 시간표** — 에브리타임 시간표를 캡처해 올리면 AI가 과목·시간·강의실을 읽어 채우고, **과목 폴더까지 자동으로 만듭니다**
- **다가오는 시험 / 이번 주 과제** — D-day와 함께. 시험이 가까워지면 상단에 "학습노트와 우선 복습 개념이 준비돼 있어요" 알림
- **알림 센터** — 분석 완료, 새 개념 발견, 시험 임박 등을 모아서

### 과목 · 수업 폴더

- 과목(강제) > 폴더(자유 이름) 2단 구조. 주차별이든 챕터별이든 원하는 대로
- 자료를 드래그해 넣으면 **즉시 백그라운드 분석 시작**
- 지원 형식: PDF · PPT/PPTX · 전사 텍스트(.txt) · 필기(.md) · 기출 이미지(.png/.jpg)
- 오디오 파일은 받지 않습니다 — 녹음은 전사 텍스트로 변환해 올립니다 (원본이 기기를 벗어나지 않게)
- 폴더 화면 상단에 **"에이전트가 시험에 나올 가능성이 높은 개념 N개를 찾았어요"** — 개념마다 기출 횟수·강조 횟수 표시

### 강의자료 세부 페이지 (5탭)

자료 하나를 열면 그 자료에 대한 모든 것이 한 화면에 있습니다.

| 탭 | 내용 |
|---|---|
| **슬라이드 설명** | PDF 옆에 페이지별 설명·핵심 포인트·시험 팁. 그 페이지에서 교수가 한 말(녹음본 시각)까지 연결. 출제 신호가 높은 페이지는 목차에 상·중·하 색으로 표시 |
| **강의 요약** | 이 자료를 쪽 순서대로 정리한 한 장 요약. "시험에 나올 만한 곳"을 상단에 모아서. 쪽 번호를 누르면 해당 슬라이드로 이동 |
| **퀴즈** | 이 수업 범위 예상문제. 연습 모드(바로 모범답안 확인)와 모의고사 모드(전부 풀고 채점) |
| **녹음·필기** | 이 수업의 전사본·필기 목록. 여기서 전사 텍스트를 올리면 해당 강의와 짝지어집니다 |
| **AI 챗봇** | 이 자료에 근거해 답하는 대화 (준비 중) |

### 시험 대비

시험이 다가오면 흩어진 재료를 한 권으로 조립합니다.

1. **시험 선택** — 다가오는 시험 목록에서 고릅니다
2. **범위 선택** — 이 시험이 커버하는 수업(주차)을 체크
3. 그 범위로 네 가지를 제공합니다:

- **학습 가이드** — 범위 전체를 하나로 조립한 시험 대비 가이드. 개념을 중요도 순으로, 왜 중요한지와 함께. 마지막의 **공부 순서**는 개념 사이의 선수관계를 계산해 만듭니다 — "임계 구역을 먼저 봐야 세마포어가 이해된다"처럼
- **우선 복습** — 시험 신호가 높은 개념 TOP 10. "7개 수업에서 반복 · 기출 6회"처럼 **왜 우선인지** 근거를 함께
- **학습노트** — 파인만 톤으로 쓴 누적 학습노트 (전공용어 대신 쉬운 말과 비유)
- **모의고사** — 근거 검증을 통과한 예상문제로 실전 연습

### 족보(기출)

과목마다 족보 폴더가 자동으로 만들어집니다. 기출을 넣어두면 **개념과 자동으로 매칭**되어, "이 개념은 2025·2023 기출에 나왔다"가 시험 신호 점수에 반영됩니다. 연도별 기출 카드와 스캔 이미지 갤러리로도 볼 수 있습니다.

텍스트가 없는 **스캔본·사진 기출도 읽습니다.** 세 엔진(Claude·GPT·Gemini) 모두 이미지·PDF를 직접 보기 때문에, 손으로 쓴 답안이나 촬영한 문제지에서도 문항을 추출합니다.

### 에이전트 화면

분석이 지금 무엇을 하고 있는지, 지금까지 무엇을 했는지 보여줍니다. 실행 로그, 활동 기록, **능동 제안**(에이전트가 먼저 "이 개념들이 시험에 나올 것 같다"고 알려준 내역).

## 이 제품의 세 가지 원칙

### 1. BYO-AI — AI 엔진은 사용자가 고른다

이미 쓰고 있는 **Claude·ChatGPT 구독**을 연결하거나, **Gemini API 키**(무료 발급)를 넣으면 됩니다. 앱은 키나 계정을 소유하지 않고, 엔진은 언제든 바꿀 수 있습니다.

서버가 없으므로 **운영자도 사용자도 추가 AI 비용이 들지 않습니다.** 이미 내고 있는 구독으로 학기 내내 씁니다.

### 2. 로컬 우선 — 자료도 기억도 내 컴퓨터 안에

강의 자료와 분석 결과는 전부 사용자 기기(`~/Aone`)에 저장됩니다. 원본은 기기를 벗어나지 않고, 지식베이스는 로컬 SQLite입니다. 서버로 올라가는 것이 없습니다.

### 3. 모든 산출물에 근거

개념·예상문제·학습노트의 모든 문장에 원 출처가 붙습니다 — 녹음본 발화 시각, 슬라이드 페이지, 기출 문항. "답"이 아니라 "이해"를 겨냥합니다.

생성된 예상문제는 **출처가 실제로 존재하는지 대조**해 통과한 것만 보여줍니다(환각 차단).

## 무엇이 다른가

**중요도를 코드가 계산합니다.** LLM은 "어디에 무엇이 있는지" 추출만 하고, "왜 중요한가"는 결정적 가중 함수가 계산합니다.

```
importance = w₁·등장 + w₂·근거 + w₃·강조 + w₄·기출매칭
examSignal = w₅·강조 + w₆·시험언급 + w₇·기출매칭
```

덕분에 점수를 설명할 수 있고, 같은 자료면 같은 결과가 나옵니다. 사용자·전역 설정 파일을 무시하도록 격리해 **노트북이나 계정이 달라도 결과가 같습니다.**

**"뭐부터 봐야 하나"에 답합니다.** 중요도만으로는 부족합니다 — 시험에 나올 개념이 15개라고 알려줘도 학생은 어디서 시작할지 모릅니다. 그래서 개념 사이의 선수관계를 그래프로 만들고, 위상정렬로 공부 순서를 계산합니다.

```
커리큘럼 순서   먼저 배운 개념이 선수 (수업 순서 자체가 근거)
기출 동시출현   같은 문항에서 함께 물어본 개념은 묶어서
논리적 의존     같은 주차 개념 사이의 선행 관계만 LLM이 판정
```

앞의 둘은 DB만으로 계산해 LLM을 쓰지 않고, 셋째도 주차당 한 번만 판정해 자료가 쌓여도 비용이 선형에 그칩니다.

**적용한 학습 기법**
- **파인만 기법** — 학습노트를 쉬운 말과 비유로
- **능동 회상 + 블룸 인지수준** — 퀴즈가 '왜·어떻게·차이·적용'을 묻고, 문항마다 인지수준 태그
- **증분 축적** — 자료가 들어올 때마다 개념이 병합·정교화. 단발 요약이 아니라 학기 내내 자라는 지식. "레이스 컨디션"과 "경쟁 상태(Race Condition)"처럼 표기만 다른 개념은 하나로 합쳐, 같은 개념이 여러 이름으로 흩어져 중요도가 낮게 잡히는 일을 막습니다

## 기술 구성

```
aone-app/          Tauri 2 + Next.js 15 (같은 코드가 데스크톱 앱과 웹으로)
  app/             화면 — 홈·과목·강의자료 세부(5탭)·시험대비·에이전트
  components/      PDF 뷰어·퀴즈·시험대비·기출 뷰어
  lib/             파일 브릿지·엔진 어댑터·매니페스트
  src-tauri/       Rust 셸 — 파일 감시·프로세스 스폰·경로 관리
pipeline/          분석 파이프라인 (TypeScript)
  src/layers/      L0 추출 → L1 정규화 → L2 지식 → L3 신호·선수관계 → L4 산출
  src/adapters/    LLM 어댑터 (Claude·GPT·Gemini를 같은 zod 스키마로)
  src/db.ts        로컬 SQLite (개념·근거·신호·점수·선수관계)
scripts/           사이드카 스테이징 (Node 런타임 + 파이프라인 번들)
```

**5계층 파이프라인** — L0·L1은 코드가, L2·L4는 LLM이, L3은 LLM이 추출하고 점수·선수관계는 코드가 계산합니다. 프레임워크 없이 직접 구현한 오케스트레이터가 고정 DAG로 지시하고 모든 판단을 기록합니다.

**엔진 어댑터** — 어느 엔진을 쓰든 zod 스키마로 출력 구조를 강제하고 실패 시 재시도합니다. 엔진이 달라도 같은 형태로 로컬 DB에 쌓입니다.

## 개발

```bash
# 앱 (프론트 + 데스크톱)
cd aone-app
npm install
npm run tauri:dev          # 데스크톱 앱
npm run dev                # 브라우저 (localhost:3100)
npm run tauri build        # .dmg 빌드

# 분석 파이프라인
cd pipeline
npm install
npm test                   # 유닛 테스트 46개
npx tsx src/cli.ts run --subject 데이터통신 --unit 3주차 --engine claude-cli
npx tsx src/cli.ts export --subject 데이터통신
```

주요 명령: `run`(분석) · `export`(화면용 스냅샷) · `summarize-slides`(슬라이드별 설명) · `compose-guide`(시험 범위 학습 가이드) · `recognize-timetable`(시간표 인식)

## 자료에 대해

코드는 이 저장소에 있습니다. 실제 강의 자료(전사본·슬라이드·족보)는 저작권 문제로 저장소에 포함하지 않았으며, 데모 데이터는 배포본과 웹 데모에 별도로 담았습니다.
