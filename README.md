# Aone

**강의 자료를 넣어두면 학기 내내 스스로 정리하고, 시험이 다가오면 먼저 챙겨주는 대학생 학습 에이전트**

2026 AI·SW중심대학 디지털 경진대회 SW부문 본선 출품작 · 충남대학교 **멋쟁이 차차처럼**

---

## 한눈에 보기

강의 자료를 폴더에 넣으면 그때부터 에이전트가 알아서 돕니다. 버튼을 누를 필요가 없습니다.

```
자료를 넣는다  →  지각 · 기억 · 추론 · 행동  →  시험이 다가오면 먼저 챙긴다
   PDF·전사본        개념 추출 → 근거 부착          우선 복습 · 학습 가이드
   필기·족보         교수 강조·시험 신호 감지         예상문제 · 모의고사
```

- **BYO-AI** — AI 엔진은 사용자가 고릅니다. 이미 쓰는 Claude·ChatGPT 구독이나 Gemini API 키를 연결하면 됩니다. 서버가 없고, 운영자도 사용자도 추가 AI 비용이 들지 않습니다.
- **로컬 우선** — 강의 자료와 분석 결과는 사용자 기기(`~/Aone`)에만 저장됩니다.
- **모든 산출물에 근거** — 개념·예상문제·학습노트의 모든 문장에 원 출처(발화 시각·슬라이드 페이지·기출 문항)가 붙습니다.

AI 분석과 자료 업로드는 사용자 컴퓨터의 AI로 동작하므로 데스크톱 앱에서 사용합니다.

## 데스크톱 앱 실행

**macOS**
1. `Aone.dmg`를 열고 `Aone.app`을 Applications로 드래그
2. 첫 실행 시 보안 경고가 뜨면 앱 아이콘 **우클릭 → 열기**
3. 첫 실행 시 `~/Aone` 폴더가 생기고 데모 데이터가 자동으로 채워집니다
4. Node.js 등 별도 설치는 필요 없습니다 (분석 엔진이 앱에 내장)

**AI 엔진 연결** (설정 → 엔진, 셋 중 하나)
- Claude 구독 (Claude Code CLI 로그인)
- ChatGPT 구독 (Codex CLI 로그인)
- Google Gemini API 키 ([무료 발급](https://aistudio.google.com/apikey))

## 동작 원리

### 5계층 파이프라인

| 계층 | 하는 일 | 주체 |
|---|---|---|
| **L0 추출** | PDF·PPTX·전사본 → 텍스트·페이지 | 코드 (pdf.js·officeparser) |
| **L1 정규화** | 발화 블록·슬라이드 정돈, 위치 정보 보존 | 코드 |
| **L2 지식** | 개념 추출 + 근거 부착, 과목 단위 병합 | LLM |
| **L3 신호** | 교수 강조·시험 언급 추출 → **점수는 코드가 계산** | LLM은 추출만 |
| **L4 산출** | 예상문제·학습노트·능동 제안, 근거 실존 검증 | LLM |

**핵심: 모델이 아니라 모델을 부리는 코드.** LLM은 "어디에 무엇이 있는지" 추출만 하고, "왜 중요한가"는 결정적 가중 함수가 계산합니다.

```
importance = w₁·등장 + w₂·근거 + w₃·강조 + w₄·기출매칭
examSignal = w₅·강조 + w₆·시험언급 + w₇·기출매칭
```

덕분에 점수를 설명할 수 있고, 같은 자료면 같은 결과가 나옵니다.

### 환각 차단

생성된 예상문제의 출처가 실제 근거 DB에 존재하는지 대조해, **통과한 문항만** 사용자에게 보여줍니다.

### 적용한 학습 기법

- **파인만 기법** — 학습노트를 전공용어가 아니라 쉬운 말과 비유로 씁니다
- **능동 회상 + 블룸 인지수준** — 퀴즈가 단순 암기가 아니라 '왜·어떻게·차이·적용'을 묻고, 문항마다 인지수준을 태그합니다
- **근거와 출처** — 모든 문장에 원 출처를 붙여 "답"이 아니라 "이해"를 겨냥합니다

## 기술 구성

```
aone-app/          Tauri 2 + Next.js 15 데스크톱 앱 (같은 코드로 웹 병행)
  app/             화면 (홈·과목·강의자료 세부 5탭·시험대비·에이전트)
  components/      PDF 뷰어·퀴즈·시험대비·기출 뷰어
  lib/             파일 브릿지·엔진 어댑터·매니페스트
  src-tauri/       Rust 셸 — 파일 감시·프로세스 스폰·경로 관리
pipeline/          분석 파이프라인 (TypeScript)
  src/layers/      L0~L4
  src/adapters/    LLM 어댑터 (Claude·GPT·Gemini를 같은 zod 스키마로)
  src/db.ts        로컬 SQLite (개념·근거·신호·점수)
scripts/           사이드카 스테이징 (Node 런타임 + 파이프라인 번들)
```

**엔진 어댑터** — Claude·GPT(Codex)·Gemini 어느 쪽을 쓰든 zod 스키마로 출력 구조를 강제하고 실패 시 재시도합니다. 엔진이 달라도 같은 형태로 로컬 DB에 쌓입니다.

**재현성** — 사용자·전역 `CLAUDE.md`/`AGENTS.md`를 무시하도록 격리해, 노트북이나 계정이 달라도 같은 결과가 나옵니다.

## 개발

```bash
# 프론트 + 데스크톱 앱
cd aone-app
npm install
npm run tauri:dev          # 데스크톱 앱 (개발)
npm run dev                # 브라우저만 (localhost:3100)
npm run tauri build        # .dmg 빌드

# 분석 파이프라인
cd pipeline
npm install
npm test                   # 유닛 테스트 46개
npx tsx src/cli.ts run --subject 데이터통신 --unit 3주차 --engine claude-cli
npx tsx src/cli.ts export --subject 데이터통신
```

주요 CLI 명령: `run`(분석) · `export`(화면용 스냅샷) · `summarize-slides`(슬라이드별 설명) · `compose-guide`(시험 범위 학습 가이드) · `recognize-timetable`(시간표 인식)
